Here's the verdict on why the model underperforms market:

---

**This is a real defect, not an efficient-market wall.** The evidence from both reports shows the raw ensemble blend was never mathematically capable of concentrating weight on the market even when the data justified it — that's a fitting-mechanism flaw, not proof the market is unbeatable.

**The mechanical reason:** `fitEnsemble()` in `nfl-ensemble.js:1619-1628` doesn't run a joint regression. Each of the ~20 component models gets a weight from `exp(-0.7 * its_own_standalone_RMSE)`, normalized independently (`:1632-1634`). There's no matrix solve, no covariance term, nothing that accounts for redundancy between components. Concretely: a component that's 2 RMSE points worse than market still keeps 25% relative weight (`exp(-0.7*2) = 0.25`), and two correlated components (like `market_anchor` and `market_regression`, both already anchored near market) each get counted separately instead of being recognized as redundant. So noise and duplication don't get shrunk out — they get systematically preserved. That's what drags the blend to 14.8 RMSE against market's 13.5. Report 2 confirms this isn't a caching or lookahead artifact — the audit path (`nfl-blind-audit.js:295` → `fitEnsemble` with `beforeWeek` cutoffs at `:1315-1318`) is a genuinely fresh, walk-forward fit each week. The defect is in the weighting formula itself, not in how it's being tested.

**Is this the same as the 0/848 gate finding? No — genuinely separate.** The gate (`residual_gate_passed`, `:1657-1662`) only controls `residual_weight`, which only feeds `residualMargin`, which only matters in `blendMode: 'market_residual'` — production's actual mode. So production has never let its residual blend diverge from market (that's the earlier finding: production is market by construction). But the audit runs `blendMode: 'raw'` (`nfl-blind-audit.js:295`), which uses `margin_weight` — completely ungated, always active, never touched by that gate. Same file, same `fitEnsemble()` call, two independent weight sets, two independent problems: one blend is neutered by a gate that never opens; the other is active but structurally can't converge toward market. Neither one currently beats market, for different reasons.

**The fix:** Replace the per-component exponential weighting in `rawWeight()`/`margin_weight` (`nfl-ensemble.js:1619-1634`) with an actual regularized joint regression — ridge or OLS of realized margin on all 20 component predictions simultaneously, still fit walk-forward using the existing `replayWindows()` cutoff logic so no lookahead is introduced. That's the mechanism that can properly shrink correlated/noisy components toward zero and let weight concentrate on market when justified — which the current formula cannot do at any sample size. This is scoped: it only touches the weight-fitting step, not the walk-forward evaluation harness, which Report 2 already validated as sound.
