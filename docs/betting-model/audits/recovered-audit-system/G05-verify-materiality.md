# G05 verify (lens=materiality) — Historical audit grades a forecast that is not served (raw vs market_residual)

Verdict: REFUTED AS P1 — downgrade to a labelling/provenance item (P3). The code-truth verifier's facts all stand (replay never sets blendMode; ensemble default 'raw'; board defaults 'market_residual'; blind audit inherits raw; no spec/label records it). What does not stand is the materiality: closing the gap changes no decision, no forward-record validity, and the only "number Nick reads" it could change would move toward a LESS informative zero-spread-bet audit, because the served blend is, at every cutoff ever fitted, exactly the market line.

## 1. The served blend is the market line at every cutoff — so a "served-blend audit" is a zero-spread-bet audit

- Gate: nfl-ensemble.js:1187-1189 `m.residual_gate_passed = (includeChallengers || !m.challenger_only) && m.residual_diagnostic_passed; ... m.residual_weight = m.residual_gate_passed ? Math.exp(-0.7 * m.residual_rmse) : 0;` (diagnostic at 1183-1184 requires `residual_n >= 250 && residual_rmse_gain >= 0.03 && residual_paired_t <= -1.645`).
- Fallback: nfl-ensemble.js:1293-1295 `const residualMargin = marketMargin != null && residualWeight > 0 ? marketMargin + ... : marketMargin;` and 1299 `const margin = blendMode === 'market_residual' ? residualMargin : rawMargin;` — comment 1296-1298: "The no-signal fallback is precisely the spread."
- DB (read-only, 847 rows of nfl_ensemble_fit_artifacts, fit versions v7/v8/v9/v10, cutoffs 2016–2026 plus 'live', champion- and all-inputs): `with_residual_pass = 0` in EVERY (season, version, input_mode) group; `passing_ids: []` everywhere. Examples: 2022|v10 max_gain 0.035 / max_t -1.919 / max_n 488 (never on the same model at the same time); 2025|v10 max_gain 0.005; 2026|v10 champion max_gain 0.001, max_t -0.086; live|v7 max_t -0.514. No component has ever cleared the residual-skill gate.
- Consequence for a market_residual replay: `e.projected_margin == marketMargin` → nfl-replay.js:234 `const edge = e.projected_margin - marketMargin;` = 0 for every spread candidate → nfl-policy.js:21 `minEdge: 3` / :201 `abstentionReason = 'edge_below_threshold'` → zero spread bets. Totals are blend-independent (nfl-ensemble.js:1289 `const total = blend('total', 'total_weight');`), so the 48-bet / -2.945u total line would be unchanged. Moneyline is not a served market (nfl-policy.js:20 `markets: Object.freeze(['spread'])`).
- The replay's own design note anticipates exactly this: nfl-replay.js:210-211 "It intentionally does not apply today's calibration gate retroactively: that would turn a losing audit into an artificial zero-bet backtest." Forcing the served blend into the historical replay produces that artificial zero-bet backtest by another route.

So the raw audit is not grading "a forecast that is not served" in any decision-relevant sense: it is the only replay that measures whether the components carry closing-line edge at all (answer, runs 27/32: 153-156 spread bets, -7.1% to -7.75% ROI, 95% ROI interval spanning zero per IMPLEMENTATION-SUMMARY.md:41-46). The served blend adds nothing to that question because it IS the market.

## 5. Re-rating trigger

This becomes material the day any component passes the residual gate (a fit artifact with `residual_gate_passed: true`): from then on the served forecast diverges from the market and the raw audit's spread record would no longer describe what production serves. Until then the two forecasts differ only in that one of them has no edge to grade.
