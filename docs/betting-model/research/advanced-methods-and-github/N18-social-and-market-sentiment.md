# N18 — Social-media / market-sentiment signals: honest literature verdict + Gridiron attachment points

## Repo grounding (read tonight, read-only, fantasy-football-dashboard)

Gridiron already has a substantial "crowd information" layer, but it is deliberately **not** sentiment-scored:

- `server/news/twitter-ingest.js` — ingests insider-beat-reporter tweets (Schefter, Rapoport, Pelissero, etc., a *curated* handle list, not keyword search) through the same typed-claim extractor as RSS news. Explicit design comment: "never a sentiment score, never a number derived straight from tweet text. A tweet earns exactly as much trust as an ESPN story with the same words, no more."
- `server/services/twitterapi-io.js` — twitterapi.io client with a **hard, DB-persisted spend cap** ($10 soft-limited at $9.50), cost tracked per call ($0.15/1k tweet reads, $0.18/1k profile reads). Any new social-sentiment feature that reads tweets rides this exact budget rail — it is not free capacity.
- `server/services/nfl-news-signal.js` — typed injury/status extraction with a source-verification gate (`newsSourceVerification`): a social handle needs a *live-validated* entry in `news_source_validation` before its claims can reach any model feature. Aggregate "vibes" from unverified accounts structurally cannot enter this pipeline today — that's a design choice, not an oversight.
- `server/services/nfl-tweet-line-correlation.js` — **already exists** and is the closest thing to a "does social signal move the market" test in the codebase: on a stored insider tweet, it snapshots the team's current spread/total as baseline and checks 48h later whether it moved beyond a noise floor (0.5 pts). Self-documented limits: forward-only (no historical intraday archive before 2026-08-05, same constraint as the prop-CLV work), and a move is correlation not proof of causation — an AI explainer is told to say so when the link isn't clean. **This is the natural home for any new market-reaction-to-sentiment work**, not a new module.
- `server/services/prediction-markets.js` — the "market sentiment" side (Kalshi order book + Polymarket), explicitly framed as a hypothesis test ("large aggressive flow on an exchange leads sportsbook line movement... If false, we are watching the same move arrive by a different route, and this is a data feed with no edge"), stated to still be unresolved for lack of accumulated observations. It also states the project's headline null result plainly: "our disagreement with the opening line has an r-squared of 0.0016 against subsequent movement."
- `server/db/schema/mlb-model-misc.js:562` — `polymarket_quotes` table (the 12.4M-row tape FOUND flagged as "essentially unused beyond spread-ladder construction"). Confirmed: `polymarket_markets`, `polymarket_quotes`, `polymarket_price_history` tables exist; only spread-ladder construction currently reads them.
- `server/services/nfl-clv.js`, `nfl-execution-clv.js`, `nfl-prop-clv.js`, `nfl-execution-clv-downsize.js` — confirms the FOUND finding of multiple independent CLV implementations (4+ files/tables). Any sentiment signal that wants to be graded "did it produce positive CLV" has no single place to plug into today.
- `server/services/nfl-sharp.js` — the one signal the project's own comments call out as working ("the only group that reliably beats the closing line"): SHARP_BOOKS (Pinnacle etc.) vs REC_BOOKS (DraftKings, FanDuel, etc.) divergence. This is the natural target for a *popularity-bias* sentiment signal (below), because a popularity-shaded rec-book number is exactly the kind of "stale toward the public" price this module already profits from.
- No file in the repo does public-bet-percentage / ticket-money ingestion, follower-count/engagement popularity indexing, or Reddit ingestion of any kind. No fantasy-specific sentiment code exists anywhere (confirms this is genuinely new territory, not a gap in an existing feature).
- `gh search repos` for "twitter sentiment nfl" / "sports betting sentiment analysis" / "nfl twitter sentiment betting" returned **zero** results with any real activity — there is no credible open-source project to port from. Commercial products exist (betsentiment.com) but are closed-source and unaudited.

## Primary sources read

### 1. Sinha, Dyer, Gimpel & Smith — "Predicting the NFL using Twitter" (arXiv:1310.6998, 2013)
Fetched and read (PDF, CMU/ARK group). **Sample**: 252 NFL games. **Method**: tweet-volume and simple lexicon-sentiment features about each team in the run-up to a game, logistic regression, compared against a model using traditional game statistics and against the closing betting line. **Result**: tweet-based features alone reached **55.6% accuracy against the closing spread** — better than a coin flip, roughly break-even-to-thin-edge before vig (52.4% needed to break even at -110), and the paper's headline claim is that *simple* Twitter features "match or exceed" game-stat features, not that they beat the market by a wide margin. **Limitation the authors themselves flag**: small game sample (one season), and volume/sentiment extraction is coarse (word-count style, not a trained classifier validated against held-out human labels). This is the single most-cited positive result in the space, and even taken at face value it's a marginal edge on a 252-game sample — not something that survives multiple-comparison correction applied to the dozens of feature variants such papers typically try.

### 2. Lachanski & Pav — "Shy of the Character Limit: 'Twitter Mood Predicts the Stock Market' Revisited" (Econ Journal Watch, 2017)
Fetched and read (HTML article + PDF). This is a direct replication of Bollen, Mao & Zeng (2011), the single most influential "social sentiment predicts an efficient market" paper (87.6% claimed DJIA up/down accuracy, Feb–Nov 2008). **Sample**: the replication extends Bollen's original 2008 tweet corpus backward to include 2007 data that the original authors had collected but discarded. **Method**: same Granger-causality framework, same mood-index construction approach (OpinionFinder/GPOMS-style). **Result**: the significant mood→market relationship reproduces *only* on the original truncated subsample and **disappears** once the backward-extended (fuller) sample is used — "a result consistent with data snooping." The paper's own stated conclusion: no evidence the Twitter mood measures aid out-of-sample prediction, consistent with market efficiency — and it notes as a real-world coda that Derwent Capital Markets, the hedge fund that tried to trade this exact signal, failed and closed in 2012. This is the load-bearing negative result for the entire "sentiment predicts an efficient market" literature.

### 3. Feddersen, Humphreys & Soebbing — "Sentiment Bias and Asset Prices: Evidence from Sports Betting Markets and Social Media" (Economic Inquiry 55(2), 2017; WVU working paper 13-07)
Fetched and read (repository abstract page + working-paper landing page — full PDF not text-extractable from the host, so treat the quoted findings as abstract-level, not full-body-verified). **Sample**: prices and outcomes over two seasons across seven professional sports leagues in Europe and North America. **Method**: Facebook "Likes" per team as a sentiment/popularity proxy, regressed against bookmaker-set prices. **Result**: bookmakers do shade prices favorably for teams with more Facebook likes — sentiment measurably bends the number — but critically, **teams with more favorable (sentiment-shaded) prices do not actually win more often**, i.e., the popularity bias is a real, measurable price distortion that does **not** translate into a bettable inefficiency by itself, because it's already priced correctly relative to the shaded number (the market has "corrected" for its own bias in the price it set). This is the key finding for the "new" bucket below: popularity sentiment shows up as a symptom in a *specific place* (rec-book lines vs true probability) rather than as a standalone tradeable signal.

### 4. Reddit/WSB sentiment-for-markets literature (search-level read, not full-text — flagged honestly as not read in full)
Multiple 2023–2025 papers (ACM Web Science 2024 "Highly Regarded Investors?", Oxford DPhil thesis on r/wallstreetbets, ScienceDirect 2024 retail-investor-attention study) converge on: social-sentiment text features have **weak** correlation with subsequent price moves; **volume/attention metrics** (post count, comment count, Google Trends) show a *more reliable*, if still modest, signal than sentiment polarity itself. No paper located studies fantasy-sports-specific social sentiment (DFS lineup construction, waiver-wire buzz, start/sit crowd consensus) at all — this sub-area has **no published evidence either way**, positive or negative. That absence is itself the honest finding for the fantasy side of this topic.

## Overall verdict

The literature on social-media sentiment predicting sports betting lines or outcomes is **thin, mostly old (2011–2017), and dominated by one small positive result (Sinha et al., n=252, ~55.6% ATS, no multiplicity correction) and one influential negative replication in the adjacent efficient-markets domain (Lachanski & Pav killing Bollen's headline stock result on the exact same data-snooping failure mode Gridiron's own trial-registry gap [FOUND] would let happen again)**. The one well-identified effect that *does* replicate (Feddersen/Humphreys/Soebbing) is a **popularity bias in bookmaker pricing**, not a standalone sentiment-to-outcome signal — and it is already structurally adjacent to Gridiron's one demonstrated-working edge (sharp-vs-rec divergence in `nfl-sharp.js`), which is where it should attach if it attaches anywhere. For fantasy football specifically, there is no published evidence base at all, positive or negative — building it would be entering an empirically unexplored space, which given Nick's fantasy-first priority is at least defensible as a genuine experiment, but should be treated with the same registered-hypothesis discipline as everything else, not shipped straight to production weight.

**Honest bottom line: do not build a general social-sentiment scoring pipeline.** The two narrow, evidence-grounded things worth trying are (1) mining the sentiment/popularity bias specifically as a *rec-book staleness detector* feeding the existing sharp-vs-rec engine, and (2) treating fantasy-sentiment as an unexplored, cheap, strictly-gated experiment — not a roadmap item.
