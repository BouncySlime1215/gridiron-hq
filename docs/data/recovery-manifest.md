## Recovery order if an archive is ever deliberately removed

1. Restore code and dependencies from the repository. `npm ci` is the project's documented dependency setup; use a scratch database first. Do not overwrite a running SQLite database or separate its WAL file from its database.
2. For nflverse research data, inspect the recorded asset CSV and run `scripts/line-history/nflverse_backfill.py` against a **new** output path via `NFLVERSE_DB`. Compare expected manifest assets, table schemas, and source availability before adopting it. The script defaults to the then-current release URLs unless pinned externally.
3. For odds/history, follow `scripts/line-history/README.md` and collector scripts source by source. Recover Covers and Polymarket where still available; do not assume Action Network historical ticks, paid odds snapshots, or other derived tables can be replayed.
4. For the app, use `npm run sync:data` on a fresh or isolated database, then restore private league/user/chat data from a retained trusted backup or authorized source. Verify schemas and app behavior before switching a live path. The public bootstrap alone is incomplete.
