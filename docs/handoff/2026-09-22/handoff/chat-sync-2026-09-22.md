## RULES AND LESSONS a new session must know

- **The decision test for this whole class of bug.** Not "is there a fallback" but **"can a fault reach this fallback, and if it does, can any caller tell?"** Read the callee's source to find out whether the ordinary no-data path *throws* or returns a sentinel. If no-data returns a sentinel, then a throw reaching a catch is a **real fault**, and that catch has no legitimate case at all. That is exactly how #125 was justified.
- **A counted reason can be worse than silence.** #113 counted a skip so it would stop being invisible, and thereby gave a whole-layer fault a confident, wrong label. If you add a counter, prove the only things reaching it are the thing you named. #131 is the repair.
- **The house pattern for the fix** is already in `manager-archetypes.js`: `leagueHistoryState()` / `leagueDraftPicksState()` return `{present, reason, source}` and the build surfaces `<thing>_state` / `<thing>_reason`. Deliberately **not cached** — a migration can create a table inside the life of a process. Follow it; #125 and #131 both do.
- **Make the RED fail on the defect, not on the missing field.** In #131 I reordered the middle test so it asserts the miscount before it asserts the absent state field, otherwise the RED output only evidences "no such property" and proves nothing about the bug.
- **Verify a relayed claim yourself before repeating it.** I reported a wrong root cause for main's CI red once (guessed ENOTEMPTY from a TAP-delta pattern). The coordinator relayed a correction; I reproduced it independently in a clean worktree and found the precise mechanism was different again from *both* accounts. Reproduce, then report.
- **`mcp__github__get_job_logs` silently caps at ~5000 lines** regardless of `tail_lines` (confirmed: identical 355,378-char output for 5000 and 50000). A failure earlier than that window is unreachable through it — get the relevant tail, or reproduce locally.
- **`mock.module` needs `--experimental-test-module-mocks`.** The npm `test` script passes it; a bare `node --test` does not, and fails with `TypeError: mock.module is not a function`.
- **One editor per file.** I diagnosed and fully verified the `routes/trades.js` fix and still handed it to Trade Brain rather than pushing it. That was right and should keep happening.
- **CI is ON** (public repo, free) since 14:52Z. Any PR body claiming "GitHub Actions is out of minutes" is stale — I removed that sentence from #47's body by editing the body directly, no push needed.
- **Check the PR number the API returns before writing R52.2 citations.** I guessed wrong twice (#126 → actually #131, #132 → actually #134) and had to rewrite both bodies.
- Attribution footer on every GitHub comment, and the `Co-Authored-By` / `Claude-Session` trailer on every commit.
