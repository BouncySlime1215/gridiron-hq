## RULES AND LESSONS a new session must know

1. **The wiring map resolves a receiver literally named `db` to the app
   database** (`scripts/wiring-map.mjs:384`, `DB_RECEIVERS`). Coach's
   `personVariables` held the *private chat corpus* in a local called `db`, so
   the gate reported `messages`, `jev_chat_signals` and `manager_chat_profile`
   as app tables nothing writes — ten findings, all false. The fix was the
   rename to `chatDb` (`4b7f49ec`), which is the same convention #129 named for
   `nflDb`. **If a handle is not the app database, spell out which database it
   is.** This is the cheapest class of false finding in the repository.
2. **Main's findings are not yours.** After #129 (`c90d2834`) main exits 0 on
   the wiring gate, so anything the gate reports on a branch based on it is
   that branch's own (Auditor R60). Do not attribute a finding to another
   thread without re-reading it on the merged tree — that is exactly the
   mistake the ten above were.
3. **`assert` throws on the first mismatch, so a guard reports ONE failure
   where there are two.** Coach's catalog guard hid a second stale
   runtime-creator claim behind the first. When a data-shaped guard goes red,
   write the audit that enumerates every row before fixing the one it named.
4. **Do not police another thread's files against your own standard.** Coach's
   sweep guard was walking every `*.json` in `docs/tdd/sweeps/` and failing on
   six other threads' `*.mutations.json` files, which never adopted Coach's
   schema. The fix was narrowing the guard, not editing six files Coach does
   not own (`test/coach-sweep-edits.test.js:36-38`).
5. **Merge, do not rebase, onto a pushed PR head.** #90 is 82 commits with
   existing merge commits and is somebody's checkout. Merge main in; the
   branch's own convention is merge-main-in.
6. **`switch_model` can report success on an API rejection.** It returned OK
   for `claude-opus-5-5` while `get_session` showed
   `user_switch_rejected` and `last_served_model: claude-sonnet-5`. Always
   verify with `get_session`; never report a switch from the switch tool's
   own answer.
7. **The guard form** (fleet standard): isolated `git worktree`, its own
   `npm ci`, `git status --porcelain` empty and `git write-tree` identical
   before and after, `rc=0; npm run check || rc=$?` with no `set -e` and no
   `| tee`, the log written outside the repo, and a `find -newermt` sweep
   afterward. Since #129, `npm run check` includes `check:wiring`, so one guard
   covers both.
8. **Cite RED and GREEN as `#N` + commit subject + sha, with RED's failing
   assertion quoted inline** in the evidence file (Auditor R52.2). Coach's four
   beat-reporter evidence files all carry a §0 citation table in this shape.
9. **Hand-check every classifier against real wire copy before calling it
   done.** The suspension classifier passed its first four real cases and then
   produced three bugs on the next six — including a *false positive*
   ("activated off the suspended list" read as still suspended), which is worse
   than a miss because it is confidently wrong. And the fix for one of them
   introduced a fourth. Fixtures do not find this; paraphrases of real
   reporting do.
