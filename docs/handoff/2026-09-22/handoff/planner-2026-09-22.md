null out essentially the entire history — trading a modest downward bias for
near-total loss of the feature.
**Correct order: merge #92 → re-ingest participation 2016-2025 → then gate.**
Costs nothing on the live season, because `pass_rushers` comes from the same
participation feed that 404s for 2026, so both are null together there.

**2. `projections.js:492` — three supports where there should be one. Owner:

mean, while the prior it is shrunk toward (`:395`) and the `k` controlling the
shrink (`shrinkage-fit.js:330`) are **both** fit on positive-only rows. That
disagreement is a defect independently of any view about zeros. Priced: 113 of
627 players affected (18.0%), ratio-of-means **21.5%** understatement, mean
0.0059 share. Two limits always carried with the number — it measures
`tgtShareObs`, the *input* to `shrink()`, so it is an **upper bound**; and snap
files covered 2023-2024 only, so seasons at `back >= 2` are absent, worth under
9% of the weight. The effect **falls** with n (Pearson −0.269 on the weighted n
`:522` actually passes to `pickK`), which both reduces the served impact and
sharpens the mismatch: the players most affected are the ones whose projection
is dominated by a prior fit on rows the observation does not use.

## 6. RULES AND LESSONS A NEW SESSION MUST KNOW

### A defect is not live until the value reaches something.
The rule this sweep produced, and it cost a withdrawn claim to learn (§5,
finding 5). **Check the column is read before pricing it.** An `AVG()` over a
contaminated column in a function nobody calls is not a bug, it is a decoration.

### Feed-zero treatment is PER COLUMN and never blanket.
nflverse writes a literal `0` — not a blank — where a measurement does not
apply, so `AVG()` has no NULLs to skip. Five distinct treatments across one
pattern. Measured verdicts live in
`docs/evidence/feed-zero-contamination-measured.md`.

| treatment | columns |
|---|---|
| `NULLIF(col, 0)` | `defenders_in_box`, `defense_box` |
| gate on a sibling column | `n_blitzers` (on `n_pass_rushers > 0`), `pass_rushers` (dropback gate) |
| `MAX(COALESCE(a,0), COALESCE(b,0))` | `offense_pct` / `defense_pct` — correct in `nfl-availability.js:194`, **wrong** in `who-plays.js` |
| leave alone | `contested` and every other boolean column — there a `0` is a real observation |
| out of scope and parked | `offseason-data.js` (offseason product is NOT APPROVED) |

### THE 3.41x TRAP — the single most important number in this document.
**A blanket `NULLIF` on `n_blitzers` lands 3.41x HIGH (1.3095 against a true
0.3838) where the original bug was 0.21x LOW.** The blanket fix is *worse than
the defect*. `n_blitzers` needs the sibling gate `n_pass_rushers > 0`, not a
`NULLIF`. Anyone who "fixes the feed-zero pattern" in one sweep will ship this.

### Migration 070 columns are NULL on every pre-existing row.
`nfl-formations.js:86-88` says so plainly: rows stored before 070 only get those
columns **on a re-ingest**. Any gate built on `was_pressure`,
`defense_man_zone_type` or `defense_coverage_type` must come **after** a
participation backfill, or it nulls the history. See §5, finding 1.

### The participation feed is HISTORY-ONLY. FTN charting is LIVE.
Measured by HTTP probe on the release path the repo itself uses, 2026-09-22:

| season | 2019 | 2020 | 2021 | 2022 | 2023 | 2024 | 2025 | 2026 |
|---|---|---|---|---|---|---|---|---|
| `ftn_charting` | 404 | 404 | 404 | **206** | 206 | 206 | 206 | **206** |
| `pbp_participation` | — | — | — | 206 | 206 | 206 | 206 | **404** |

`nfl_play_formations` has **exactly one writer**, `ingestFormations` at
`nfl-formations.js:89`, and it reads participation. So anything built on the 070
columns **cannot serve a live 2026 week**. Building on them alone designs in a
fit/serve mismatch. Build on 059 (FTN), and use 070 only as a crosswalk.

### CI runs on the MERGE REF.
It can execute gates and tests your branch has never merged in. When CI fails on
something absent from your tree, **fetch main before concluding anything**. This
thread burned real time on a `git worktree` that showed `scripts/wiring-map.mjs`
missing while CI was running it.

### `npm run check` NOW includes the wiring gate.
As of #129 (`c90d2834`): `typecheck && lint && check:wiring && test && build &&
start:smoke`. Before that it did not, and a clean `check` was not the same as
green CI. If you are reading this on an older tree, run `check:wiring`
separately.

### Separate YOUR gate findings from the BASE's before acting.
Run the same check in a detached worktree at `origin/main` and diff the finding
sets. The base's are not yours. This is how #92's four consecutive red CI runs
were correctly diagnosed rather than "fixed".

### A failing test is never a flake until proven.
And "no API key" is not a cause. This project read a `Connection error.` as a
missing key for weeks; PR #7 found a `mock.module()` call passing
`exports: { default: … }` where the API takes `defaultExport`. It was never the
key.

### Other standing rules
- **Secrets**: environment variables only; read a value's **presence**, never its
  content. Nothing paid, ever.
- **Errors are handled or they throw.** No bare `catch {}`. If a layer goes
  inert, the surface must say so.
- **Parameterised queries only.**
- **One editor per server file.** Report findings in someone else's file up to
  the coordinator rather than editing.
- **TDD**: RED commit, GREEN commit, evidence file under `docs/tdd/`, mutation
  testing with a no-op control. A surviving mutation means the test is wrong —
  or that the code is redundant and should be deleted.
- **R52.2 citation format**: cite RED and GREEN as `#N · commit subject · sha`,
  carry the RED's failing assertion inline, and verify sha reachability from the
  PR head.
- **Licence is a gate before any measurement** of an external source. Sharp
  Football was refused on licence and stays refused — unlicensed, sourced from a
  restricted sheet, on an endpoint whose own index says it exists to serve that
  site's widgets. *Reachable without a key is not permission.*
- **Never rename an applied migration. Never delete
  `/data/data.sqlite.pre-migration-*.bak`.**
- **NOT APPROVED, never build**: multi-platform league import, offseason
  product, monetization, banning narrative features. Betting is out of scope.
