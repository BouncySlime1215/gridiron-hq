**Rule:** if a season's data was read by any analysis of a given quantity — including an analysis later withdrawn — that season is burned as a held-out/validation season for that same quantity. A retraction removes the withdrawn claim, not the fact that the season was looked at. Applying k-selection or a parameter choice's evaluation on a season already used to arrive at a nearby candidate value (even a rejected one, e.g. the withdrawn ypc=115) contaminates any later "held-out" claim on that season for that quantity.

Origin: Explorer's K-yards-per submission (ypt k=64-70 beats 34 held-out 2024; ypc 115 WITHDRAWN, 34 stands) — Auditor R31 accepted the ypt evidence but used the occasion to register this as a standing rule, since the withdrawn ypc=115 candidate had already been evaluated against 2024 before the ypt work reused that season.
