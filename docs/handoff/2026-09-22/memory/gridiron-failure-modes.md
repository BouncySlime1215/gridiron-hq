a job whose product IS a module-level memo (trade_asset_universe_warm, compute-cache.js:24): off-thread it reports success and warms nothing; an allow-list read on one of two paths (MAIN_THREAD_ONLY, boot only), held by luck of defaults; three no-op injections in one night reported clean, file unchanged; a coverage check whose caller names no expectation, so it cannot fail (usageCoverage() with no window); a causal sentence in a PR body ("the remaining gap is the double-counting") naming a mechanism the author could picture but never measured, retracted when split by it (Opportunity #72, 2026-09-20); a surface count ('four surfaces') never grepped, actually six (UI step 4, 2026-09-20); a ledger head content-identical to the pushed line but not its ancestor (wiring map cdec951 vs 0eb8b6b, 2026-09-20), caught only by merge-base --is-ancestor.

**Rules:** test every checker on a deliberately broken copy; RAN is weaker than PRODUCED; verify the consumer, not the producer; the author is the worst reviewer of their own checker (trusted after a second thread runs it on a tree they did not build); the wiring map cannot see value-level mismatches in a correctly wired graph; read the code consuming a URL, not the URL's shape; a memory file's `description` is what recall ranks on; a wrong one travels furthest; a "this stays suppressed" pin needs a case strictly inside the suppressed region, not on its edge; verify a diff by content (grep the call), never by line number; an off-thread job driven through runIfStale tests the thread, not the work: split the wiring assertion from the behaviour one, delete neither (scheduler, 2026-09-20); a producer's test cannot see a consumer-contract defect: every client-read served field is unpinned by default (feature-audit, 2026-09-20).
