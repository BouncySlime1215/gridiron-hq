## 3. HOW IT RUNS
Data jobs (scheduler.js, heavy tier off-peak) -> feature tables -> models (registry; promoted only) -> Championship Engine (sim + planner; heavy runs on the Mac/worker, results cached in sim_state and action_prices) -> routes (/api/trades, /api/model) -> pages. Event bus (news ingest, ESPN sync transactions, line moves, waiver runs, counters received, live scores) -> incremental re-sim of the touched league -> re-rank -> alerts (in-app; push after N12). Every card reads one producer (CE-09). Local-only data (dossiers, twins' retrieval index, Nick's voice) stays on this Mac and feeds the app through aggregate fields only. Jev calls are metered (ai_usage) against Nick's weekly cap.
