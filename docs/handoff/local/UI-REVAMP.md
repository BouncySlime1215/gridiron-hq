# UI REVAMP PROGRAM (Nick 2026-09-23 ~3 AM ET: "UI needs to be insane, almost a full revamp of my UI on platform and front end, how we do things"). Runs alongside the Trade Machine; the UI standard (UI-STANDARD.md) is the bar.
Why a revamp, not patches: the new product is decision-first (title odds, offers, lineups), and today's pages are feature-first (projections, tables). Every screen becomes "what should I do now, and why".
## Stages
UX-01 Audit and benchmark (Sonnet researcher + browser pane): screenshot every current page and state on the local server (desktop, 375 px, dark); benchmark against the best fantasy and trading apps (Sleeper, ESPN, FantasyPros, KeepTradeCut, Underdog, Robinhood-style portfolio UIs); a teardown doc with what to steal and what to kill. Deliverable: docs/ui/audit/ with screenshots and the teardown.
UX-02 Information architecture: the 8 tabs re-cut around decisions: My team (odds ladder, doomsday, report card), Trade Brain (war room), Trade Lab (evaluate any deal), Start/Sit (guard, floor/ceiling, windows, live), League Hub (manager reads, streams, command center), News (research + briefs), Draft (seasonal), Settings. Nav stays 8. Deliverable: IA map + user flows (Tuesday trade run, Sunday lock run, counter received).
UX-03 Design system v2 on top of C-12 (#73): tokens (colour meaning, type scale, spacing, motion), dark and light, and the shared components: OddsLadder, SignalChip, TagPill, ScenarioCard, ReportCard, ReceiptCard, GuessLabel, EvidenceDrawer, OneTapAction with confirm, Skeleton/Empty/Thin/Error/Stale states. Deliverable: a component gallery page (dev-only route) with every state.
UX-04 Hi-fi designs per tab (Design artifact via quickstart when Nick wants to review visually), mobile first, then desktop columns. Nick approves each tab before build.
UX-05 Build per tab (lean-build.js, Sonnet builders; ui skeptic screenshots every state; Opus skeptic for any number shown): My team -> Trade Brain -> Trade Lab -> Start/Sit -> League Hub -> News -> Settings -> Draft.
UX-06 Platform: route-level code splitting, cached engine results so pages paint under 1 s, optimistic one-tap actions, offline-tolerant command center, PWA install + push after N12, error boundaries per card.
UX-07 Polish loop: weekly UI review against the standard; R6 files units; Nick's thumbs on cards feed AI-11.
## Order: UX-01 and UX-02 now (read-only, no product change), UX-03 with the design system PR, UX-04 per tab before its build, UX-05 in the order the Trade Machine lands its data (My team and Trade Brain first).
