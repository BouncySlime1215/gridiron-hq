# INT-159-1: remove eventOdds, an any-sport door into the paid Odds API

Unit: INT-159-1 (WORK-QUEUE.md row, plan item F "paid-call hygiene").
Non-statistical unit (no model number produced): no pre-registration needed.

## Audit (extend-or-build)

`server/services/odds-api.js` exports `sportEvents`, `gameOdds`, `playerProps`
(all NFL-only, hardcoded `SPORT = 'americanfootball_nfl'`) plus `eventOdds`,
the one function in the file that takes a caller-supplied `sport` string and
sends it straight to `https://api.the-odds-api.com/v4/sports/${sport}/...`
with no allowlist -- an any-sport door into a paid API.

`git grep -w eventOdds server scripts client/src` (tree `89f69b3b`, before this
unit's commits) found exactly two hits, both comments describing it, zero
callers:
- `docs/wiring/WIRING-MAP.md:366` (autogenerated by `scripts/wiring-map.mjs`;
  self-corrects on next `npm run check`, not edited here) -- names a second,
  differently-shaped `eventOdds()` in `server/services/parlay-api.js`, a file
  that **does not exist on this tree** (deleted with the rest of the MLB parlay
  code; the doc entry is stale but out of this unit's file allocation).
- `test/mlb-removed.test.js:222` -- a comment describing `eventOdds` as still
  live and shared. Fixed in the RED commit (see below).

Nothing to extend: this is a straight removal, not a new producer. No new
table, column or number is added, so "one number, one producer" and the
route/job/page reader requirement don't apply.
