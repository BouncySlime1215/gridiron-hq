# E1-DATA: one producer of decided offers

## Problem
Four counts of "decided offers" for the same 2026 ESPN leagues (E1 loader 37, R&D 77, a league study 82, league-4 baseline 21). Each reader re-derived the set with its own rules.

## Change
- `server/services/eval/decided-offers.js` is the one producer: one row per ESPN proposal (league, season, proposal tx id), the raw answer authoritative, trade_outcomes lending recorded predictions, #247 snapshots filling missing proposals when that table exists. Every excluded row is counted under exactly one named rule, per league.
- `e1-league.js` `mergeOffers` / `loadLeagueOffers` read the producer. Scoring as of the proposal time is unchanged.
