# IS-TITLE: importance sampling for Nick's title paths (shadow)

ONE-PLAN.md section 4d (night 2): "ADD importance sampling for Nick-title paths
(IS-TITLE) because 1,200 runs cannot resolve a 0.1-0.5% title chance"; spot-check
row 5. That is the whole unit detail; the design below is assumed.

Flag: `GRIDIRON_IS_TITLE=1`. Default off, and preview mode does not turn it on.
Shadow only: no served number reads it.

## What changed

- `server/services/correlation.js`: `correlatedSampler(...).tilted(counter, shift)`
  draws the same keyed normals with player i moved by `shift[i]` before the
  Cholesky mix, and returns the draw's log likelihood ratio
  `sum(-shift*e - shift^2/2)`. The plain `sample(counter)` is unchanged (the
  quantile lookup moved into a shared helper).
- `server/services/is-title.js` (new): the flag, the pre-registration, `tiltShifts`
  (theta spread evenly over the target's expected starters in every simulated
  week, so the total squared shift is theta^2), the plain (unbiased, not
  self-normalised) weighted estimator and its SE, weight diagnostics (mean
  weight, Kish ESS), and the shadow summary.
- `server/services/season-sim.js`: `titleWorldIS` (tradeImpactWorld's seed, pools
  and copula, tilted draws, per-run weights), `titleOddsIS`, `tradeImpactIS`
  (paired delta on the same tilted draws). `lineupPoints` takes an optional Set
  to report who started (used to pick the tilted players).
- `scripts/campaign/league-adapter.mjs`: `adapter.isTitle()` builds the IS world on
  w0's seed, run count and projections.
- `scripts/campaign/produce-plans.mjs`: with the flag on, `_run.inputs.is_title`
  holds the shadow row beside `served_title_now`. Off, the entry is unchanged.

## Measurement (pre-registered bars; test/is-title-bench.test.js, IS_TITLE_BENCH=1)

Fixture: made-up 8-team league, target team plain title odds 0.389% (100,000-run
reference, SE 0.020 pp). K = 20 seeds x 1,200 runs, each seed its own world.

| metric | bar | result | verdict |
|---|---|---|---|
| M1 levels SE ratio (SD over seeds, IS / plain) | <= 0.5 | 0.733 (0.00128 / 0.00174) | FAIL |
| M2 bias vs 100k reference | within 3 SE (0.00104) | -0.00076 | PASS |
| M3 mean weight within 3 SE of 1 | 20 of 20 | 20 of 20 | PASS |
| M4 paired delta SE ratio | <= 0.6 | 0.861 (0.00380 / 0.00441) | FAIL |
| M4 bias vs 100k paired reference | within 3 SE (0.00293) | +0.00101 | PASS |
| M5 served numbers | only `_run.inputs.is_title` added | unit test 7 | PASS |

Diagnostics: the proposal wins 30.9 titles per 1,200 runs against 4.2 plain (7.3x
the paths), but the within-seed reported SE ratio is only 0.59 (median), and the
spread over seeds (0.73) also carries each seed's own outcome-pool noise, which
no run-level variance reduction touches (season-sim.js `binomial95` comment).

Reading: unbiased and correctly weighted, but theta 1.5 spread evenly over every
simulated week does not reach the bar. Likely cause (inferred, not measured):
most of the shift lands on regular-season weeks, which decide seeding, while the
title is decided in the 2 bracket weeks, so title runs carry noisy weights. Not
tuned: per the registration, a different tilt is a new registration with its own
date.

Runtime: the full bench (about 300,000 simulated seasons, both arms counted) takes 74 s on the cloud box.
