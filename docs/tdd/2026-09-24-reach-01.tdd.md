## Scope

In this unit, in the plan's order:

1. `dropped_by_reason`: per risk mode, how many scored paths each gate removed
   (tolerance sliders by kind, the all-in `p_complete` floor, the fresh-dice
   confirm), plus the search-level count the no-overpay cap turned away and the
   targets the reach filter skipped. Numbers the planner already computes,
   aggregated; nothing new is priced.
2. Reach filter before the top-N target slice: a target is skipped only when no
   path shape the search can build could read fair on its owner's screen
   (`fairBand(value).lo` above the best package a direct give, a one-chip chain
   or a two-chip chain could hand over). A necessary-condition bound, so it can
   only skip targets the search could never have found.
3. `--targets 8` in the refresh loop's producer launch.
4. The chained finish and `flipReach` package up to the risk mode's
   `max_give_per_step` (today both are fixed at 2).
6. The closest miss prints its whole chain (first leg, then the overpaying
   finish), not just the last step.

Out of this unit: item 5 (GETS-REAL floor) is unit GETS-FLOOR; trade memory is
unit TRADE-MEMORY. Both run in their own threads and branches.

## Flag

`GRIDIRON_REACH`: `1` on, `0` off, unset follows the preview switch
(`preview-mode.js#previewUnconfirmed`), the house pattern. Items 2, 3 and 4 run
only when it is on; off, the planner and the loop launch are today's. Items 1
and 6 are diagnostics and text: always on, and they move no number.
