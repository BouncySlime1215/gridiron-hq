## Pre-registration (written before the GREEN code)

- N for a manager: p90 of that manager's reply hours when they have >= 5 answers, else the
  league's pooled p90 (>= 5 answers), else no basis. Hint: wait < N <= follow_up < 2N <=
  withdraw_or_resend (the 2x is a guess, labelled so).
- Metric: late-answer rate, time-forward. Answered offers in proposal-time order; each gets the
  N computed only from answers DECIDED BEFORE it was proposed. Late = its reply took longer than
  N (the hint would have said chase or withdraw an offer that was going to be answered).
- Pass bar: n_graded >= 30 AND late rate <= 0.15.
- Fails it: late rate > 0.15 with n >= 30. Below 30 it reads "not graded: n=k of 30" and the
  hint stays shadow (`shadow: true` on every hint).
