# E-XGB phase 2 — arm B, shadow forecasts, weekly grader, settings lock

Branch `claude/local-exgb-phase2`. Shadow only: nothing here is served. `GRIDIRON_EXGB=1`
turns the pipeline on, and preview mode never does.

## RED

`test/exgb-shadow-grader.test.js` and migration 107, committed before the flag, shadow and
grader services existed. The suite failed on the missing modules.

## GREEN

- `server/services/exgb-flag.js`: the only reader of `GRIDIRON_EXGB`, `GRIDIRON_EXGB_PYTHON`
  and `GRIDIRON_EXGB_MODEL_DIR`.
- `server/services/exgb-shadow.js` and job `exgb_shadow_predict`: runs the locked
  `exgb_shadow.py predict` at each ESPN capture window, and appends every arm's forecast to
  `exgb_shadow_predictions` (late rows flagged).
- `server/services/exgb-grader.js` and job `exgb_weekly_grade`: grades each finished week
  into `exgb_weekly_grades`. Each row holds n, MAE for the model, frozen ESPN and our
  projection, and the running week-blocked bootstrap with Holm across positions and the
  pass bar. Rows before the 2026-12-15 outcome freeze are marked provisional. A row is
  written only when its inputs change.
- `scripts/eval/exgb-benchmarks.mjs` prints the table.
- Python pieces:
  - `exgb_arms.py`: the arms, the grids, the selection rule and the lambda fit.
  - `exgb_lock.py`: the settings lock.
  - `exgb_shadow.py`: `fit` and `predict`. Both refuse to run if the code or artifacts no
    longer match the lock.
  - `exgb_panel.py`: gains a forecast mode. Test: a forecast row's features equal the
    finished row's, and a row is never selected by having played that week.

Nine JS tests and 16 Python tests (through `test/exgb-panel-leakage.test.js`). They cover:

- the flag, and that preview mode does not set it;
- late forecasts, which are never graded;
- UPDATE and DELETE refused on the new tables;
- the actual-points source and its counted fallback;
- population and fallback counting;
- the bootstrap's determinism;
- `not_run` below 6 weeks, pass at 6, and Holm never lowering a p-value;
- regrading only on change;
- one forecast per window, and a predictor failure recorded as an error;
- job order on the refresh loop;
- the lambda fit's bounds, the grid cap, the frozen-ESPN rule and forecast-mode equality.
