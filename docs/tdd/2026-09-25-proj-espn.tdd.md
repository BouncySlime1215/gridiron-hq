# PROJ-ESPN: served weekly projection = frozen ESPN (ours in shadow) + calibrated ranges

<!-- prereg: docs/tdd/PROJ-ESPN-PREREG.md -->

## Why

ML testbench #446, frozen week 2026-W2: our served weekly projection had the highest error at
every position (0.7-1.8 pts per player worse than ESPN's projection frozen before kickoff). Our
weekly ranges covered 65% of real lineup scores against an 80% target; ESPN plus a positional
spread covered 74%.

## What changed

| | before | after |
|---|---|---|
| served week number (`current_week_ppg`, `blend_week`) | ours (coordinator-corrected weekly engine x chance to play x betting-line lift) | frozen pre-kickoff ESPN (`espn_weekly_projection_snapshots`), league scoring when captured, else PPR; no lift on top |
| producer | `trade-engine.js#buildAssetUniverse` | the same, source switched there (`espn-week-projection.js`); lineups, Start/Sit, the lineup card, waivers, weekly ranges and the trade-finder horizon inherit it |
| missing / stale | n/a | `unknown` + reason, null number, never ours; number_health `espn_projection_stale` broken |
| ours | served | shadow: `weekly_projection_shadow` (season, week, player, scoring, ours, espn, captured_at), frozen at kickoff |
| lineup range | percentiles of the world's pool draws | same runs and ranks; each skill starter re-centred on ESPN + k x positional residual quantile (`lineup-week-range.js`, still the one producer) |
| k | n/a | 1.71, fitted 2026-09-25 on 46 frozen 2026-W2 team-weeks (80.4%); Tuesday refit rule, [72%, 88%] band |
| value gain | n/a | per-offer log + info-only finder hint and `?sort=value_gain` |
| ROS / title odds | season sim, BASIS-02 | unchanged (the sim reads no week number) |

Flag: `GRIDIRON_PROJ_ESPN` default ON, `=0` reverts to ours. Not tied to preview mode.

## Tests (RED then GREEN)

- `test/proj-espn.test.js` 11 tests: (1) served = the latest pre-kickoff capture, a late row
  ignored, league scoring first, blend.week equal, the shadow never in a response; (2) stale ->
  unknown + reason + broken health row + Start/Sit null; (2b) the stale week through the universe;
  (3) flag 0 -> ours; (4) shadow rows written and frozen at kickoff; (5) the shipped k covers >= 78%
  of the real 2026-W2 fixture (k = 1 does not); (6) refit decision band; (6b) the Tuesday job keeps
  inside the band, refits outside it, logs coverage, and number_health reads it.
- `test/offer-value-gain.test.js` 4 tests.
- RED: both files fail on main (the modules do not exist).

## Residual table

`scripts/eval/proj-espn-residuals.mjs --db <copy> --retro-dir ~/gridiron-local/evidence/exgb`:
15,312 played player-weeks with ESPN >= 3 (QB 2,150, RB 4,355, WR 6,969, TE 2,838), 2022-2025
ESPN RETRO projections vs actual PPR. Quantiles (p10 / p50 / p90): QB -9.9 / -1.0 / +9.0,
RB -7.9 / -1.7 / +8.0, WR -7.6 / -1.6 / +8.4, TE -5.8 / -0.8 / +7.6.

k fit (4,000 draws per team-week): frozen W2 46 team-weeks -> k 1.71, 80.4%. The same k covers
91.3% of the W1 RETRO team-weeks (RETRO is biased narrow, which is why it was not fitted on) and
85.9% pooled. At k = 1 the frozen set covers 63%.
