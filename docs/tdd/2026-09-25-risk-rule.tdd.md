# RISK-RULE: one decision rule per risk mode (2026-09-25)

ONE-PLAN.md section 4d, night 3: "risk rule per mode (Safe = worst case, Balanced =
minimax regret, Fuck-it = expected title odds)". Shadow: behind `GRIDIRON_RISK_RULE=1`,
off by default, so no served number moves until it is measured on league 4.

## 0. Audit (extend or build)

- The mode objective lives in one place, `server/services/campaign/modes.js#scorePlan`,
  called through `rankPlans` / `compareModes` by the one planner (`planner.js`). Extended
  there; no second scorer.
- Legacy rules (kept, flag off): Safe = expected minus one spread; Balanced = expected;
  Fuck-it = title odds if the plan lands, with the 3% landing floor.
- The confirm pass re-scores one plan at a time (`rankPlans([re], ...)`). Regret is relative
  to a pool, so the planner now passes the confirmed deck as `ctx.regretPool` when the rule is on.

## 1. The rules (flag on)

| mode | score | eligibility |
|---|---|---|
| Safe | worst case: lowest delta over endings with a nonzero chance (a declined first offer = 0) | sliders + core-starter rule (unchanged) |
| Balanced | minus max regret over scenarios k = 1..K ("the first k offers say yes"): best of the pool and doing nothing (0) in scenario k, minus this plan's value in it. P(yes) does not enter (unvalidated until E1) | + landing floor 3% |
| Fuck-it | expected title-odds change across yes/no outcomes | landing floor 3% (unchanged) |

Ties: expected, then fewer steps (unchanged sort).

## 4. Batch B (2026-09-25): merged onto main `decf7ebf`; each mode's rule against doing nothing

Measured first, on the RULE-FUZZ leagues (#392's `test/fixtures/rule-fuzz-league.mjs`, seeds 1..300,
run from a scratch copy, not committed here), flag off vs on. With the flag on, Safe's served top card
could still end below today in 2 of 300 leagues (4 cards): a path whose first yes loses odds and whose
second offer can be declined. Safe's rule is the worst case, and doing nothing's worst case is 0, so
such a path does not beat doing nothing under Safe's own rule.

Fix: `beatsNoTrade(scored, 'safe', { rule: true })` also requires `worstCase(steps) >= 0`. Balanced
and Fuck-it stay `expected > 0`. Never looser than the flag-off gate (worst case >= 0 makes
downside_sd 0, so the legacy Safe test reduces to expected > 0).
