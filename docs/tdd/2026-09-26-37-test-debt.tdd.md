## 1. The failure was not a flake

Line 155 is test 6, "a call site inside an already-unreached function is a survivor".
Two earlier records (2026-09-23 ux-11, s19) saw it fail 7/8 and wrote it down as
pre-existing. It passes on Linux.

Cause: `scripts/route-deletion-impact.mjs` found call sites with
`git grep -n -E '\bname\b'`. git passes `-E` patterns to the platform's POSIX regex.
glibc reads `\b` as a word boundary; macOS's regex does not, so on the Mac every
symbol had zero call sites and everything a dying route touched "fell" with it.

Reproduced on Linux with a git shim that rewrites `\b` to `b` (what BSD regcomp does):
test 6 fails, 7/8, the recorded signature.
