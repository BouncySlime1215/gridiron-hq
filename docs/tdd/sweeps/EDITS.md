# The exact edit behind every mutation row

Generated by `scripts/emit-mutation-edits.mjs` from the spec files beside it, which are
the same files the harness runs. Do not edit this by hand: a test compares it against
the specs and fails if they disagree, so a row re-aimed in a spec shows up here or the
suite goes red.

Each row shows the literal text replaced and the literal text it was replaced with. The
harness requires the "before" text to appear exactly once in the file, so an injection
that no longer matches is reported NOT APPLIED rather than scoring zero failures.
